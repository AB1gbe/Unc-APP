# 2026-10-21 Session 22: "Hide when I'm online" setting

## What was asked
"Add the hide my activity setting." This was the open point in [[ADR-026 Activity and privacy]].

## What we did, in order
1. Decided the scope ([[ADR-029 Hide my activity]]): hide only the online status. While the setting is on, Unc **stops storing** the last visit. Reply time and badges stay visible. Off by default.
2. Server:
   - migration 15 `users.hide_activity`;
   - `PATCH /me { hideActivity }`, which also clears `last_seen_at`;
   - `loadUser` skips recording for these members;
   - `summaryFor` hides it as a second safety net.
3. Wrote the test first in `server/test/activity.test.js`. It fails on the old code (`git stash push -- server/src` → 1 failure) and passes with the change.
4. Client:
   - a shared `ToggleSetting` in `Account.jsx` (the email switch uses it too);
   - a new **Privacy** card;
   - Arabic texts.
5. `e2e/smoke.mjs` now finds tick boxes by `data-setting`. Its old selector would have matched both boxes, which I noticed before running it ([[Mistakes and Fixes#M72]]). It also checks that "Active now" disappears for the other person.
6. Checks:
   - `npm test` **115/115**;
   - `npm run e2e`: E2E OK;
   - `npm run e2e:ar`: ARABIC E2E OK;
   - `npm run e2e:devices`: DEVICES OK.
7. Commit `7c3af27` pushed. Docs:
   - [[Social Touches]], [[Step 29 - Hide my activity]];
   - [[Database Schema]], [[API Reference]], [[Roadmap]].
