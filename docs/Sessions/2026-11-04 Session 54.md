# 2026-11-04 Session 54: Posting images, with examples in the app

## What was asked
"Let them be able to post images and provide an example of it on the app." (The first try didn't go through; the owner said "Try again".)

## What we found
Members can already post photos everywhere: requests (up to 6), offers, chat (incl. proof photos), profile, shop cover and stories ([[Photos]]). But the demo data had **no photos at all**, so the app never showed one.

## What we did
1. `scripts/make-demo-photos.mjs` draws 11 example pictures into `server/demo-photos/` (checked each by eye; the first "table" looked like a tree stump, see [[Mistakes and Fixes#M105]]).
2. `npm run seed` attaches them through `saveFiles()`, only where a photo is missing.
3. Test `server/test/demo-photos.test.js`. `npm test`: 171 → **172**. `npm run e2e:devices`: DEVICES OK.
4. Docs:
   - [[Photos]] now has a full table of where photos can go and how members add them;
   - [[ADR-054 Example photos in the demo data]];
   - [[Step 54 - Example photos in the demo data]].
