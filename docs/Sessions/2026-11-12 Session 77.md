# 2026-11-12 Session 77: Marketplace first

## What was asked
The owner shared design and functionality recommendations, based on the screens PDF from [[2026-11-12 Session 76]]:
1. marketplace first;
2. show the exchange on every listing;
3. follow the PDF's structure;
4. feel authored, not templated;
5. mobile as its own marketplace.

They also covered working filters, a useful request page, a shop response flow, honesty about sample data, and the whole journey. The suggested order was the requests list, then the request with offers, then the home.

## Decision asked
Should offers on a request be public? **The owner chose "shops, not prices":** everyone sees which shops answered, and only the buyer sees prices. See [[ADR-068 Marketplace first]].
