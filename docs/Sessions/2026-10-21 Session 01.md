# 2026-10-21 Session 01 — Building v1 from an empty repo

## What was asked
A fully fleshed app like Facebook Marketplace / Craigslist, but reversed: a consumer posts what they *want*; shops or freelancers contact them privately about that request. MUSTs: proper KYC, simple design, contact only about a specific listing. Everything documented in Obsidian so it can be replicated without AI. Full brief: [[01 Project Brief]].

## Starting point
Repository `AB1gbe/Unc-APP` contained only a one-line `README.md`. Environment: Node v22.22.0, npm 10.9.4, Linux.

## What we did (in order)
1. Checked the environment: Node 22.22 (so `node:sqlite` works, SQLite 3.50.4), npm registry reachable.
2. Decided platform & stack → [[ADR-001 Platform]], [[ADR-002 Tech stack]], [[ADR-003 Database]].
3. Created root workspaces `package.json` + `.gitignore` → [[Step 01 - Create the repo and workspaces]]. (**M1** `&` not cross-platform.)
4. Server: config, DB + migrations, crypto/validation/http/upload helpers → Steps 02–03.
5. Auth with cookie sessions + email codes → [[ADR-004 Authentication]], Step 04.
6. KYC with manual review + provider interface → [[ADR-005 KYC approach]], Step 05.
7. Requests (listings) → Step 06.
8. Listing-bound conversations, reporting → [[ADR-006 Messaging model]], Step 07.
9. Admin routes → Step 08.
10. Tests: 21 API tests. (**M2**, **M3** test-runner command.) All green.
11. Client: Vite + React. (**M4** Vite/plugin version clash, **M5** installing inside a workspace folder.)
12. Wrote all pages. Self-review caught **M6** (`ago()`), **M7** (date-only strings), **M8** (duplicate messages).
13. Security review of headers caught **M9** (CSP blocked `blob:` previews).
14. Playwright end-to-end run: full journey with 2 users + admin passed. Screenshots revealed **M10** (button text colour) and **M11** (stale unread badge). Fixed, re-ran → pass. (**M12/M13**: `pkill` gotchas while restarting the test server.)
15. Moved the browser test into the repo as `e2e/smoke.mjs` (`npm run e2e`), re-ran → pass.
16. Wrote this vault + `CLAUDE.md` so future sessions keep documenting.

## Options considered (summary)
| Topic | Options | Chosen |
|---|---|---|
| Platform | native, React Native, web, PWA | responsive web |
| Stack | Next.js, Django, Laravel, Rails, Express+React | Express + React/Vite |
| Database | Postgres, Mongo, better-sqlite3, Prisma, node:sqlite | node:sqlite |
| Auth | JWT, Auth0/Clerk, Passport, cookie sessions | cookie sessions |
| KYC | manual, Stripe Identity, Persona, Sumsub/Onfido/Veriff | manual + plug-in interface |
| Messaging | DMs+tag, comments, group chat, per-listing threads | per-(listing,vendor) threads |
| Real-time | WebSockets, SSE, Firebase, polling | polling |
| Files | local, S3, DB blobs, Cloudinary | local, private KYC folder |
| Styling | Tailwind, MUI, CSS modules, plain CSS | plain CSS tokens |
| Tests | Jest, Vitest, node:test, Cypress, Playwright | node:test + supertest, Playwright |
