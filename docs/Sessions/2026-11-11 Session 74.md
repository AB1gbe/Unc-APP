# 2026-11-11 Session 74: The Categories page on a real phone

## What was asked
A screenshot from the owner's phone of `/categories`: "why does it look like this on the phone".

![[phone-categories-before.jpg]]

## What was wrong
1. **A full-width orange Search button.** An old phone rule (`.searchbar > .btn { grid-column: 1 / -1 }` in `client/src/styles.css`) stretched every search button across the screen ([[Mistakes and Fixes#M131]]).
2. **The search box was focused on open** (`autoFocus` in `client/src/pages/Categories.jsx`): an orange outline, and on a phone the keyboard pops up.
3. Tiles and header looked like a website: separate label boxes under each photo, big header buttons.

## What we did
- **Search:** on phones, the field and a small **search-icon button** sit on one row (Requests also has category + area under it); on computers the button shows an icon and the word "Search". `type="search"` + `enterKeyHint="search"`, so the phone keyboard shows a Search key. Pages: `Browse.jsx`, `Categories.jsx`, `Shops.jsx`.
- **No auto-focus** on the Categories page.
- **Category tiles on phones:** square photo with the name on a dark fade at the bottom, tight gaps, no glow.
- **Header on phones:** smaller Log in / Sign up / language (still 40px tall for thumbs: [[Mistakes and Fixes#M132]]).
- Checks: `npm test` 188 · E2E OK · ARABIC E2E OK · DEVICES OK (5 × 2 × 19).
