# 2026-10-25 Session 44: Test the app on a phone without paying

## What was asked
"I don't want to pay any money now, I just want to test the build."

## What we did
1. Checked that the server already serves the built website (`server/src/app.js` serves `client/dist` after `npm run build`), so one port (4000) is enough and no code change is needed.
2. Chose a free Cloudflare quick tunnel for an https address → [[ADR-053 Free phone testing with a tunnel]].
3. Wrote [[Step 53 - Test as an app on your phone for free]]:

   - `npm run build` + `npm start`, then `cloudflared tunnel --url http://localhost:4000`;
   - install on Android/iPhone from the browser;
   - PWABuilder for a free test `.apk` on Android;
   - the limits.
