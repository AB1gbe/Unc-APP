```
npm run e2e
```

```
npm run seed

npm run e2e:devices
```

## How to see it (Windows cmd, inside `Unc-APP`, branch `claude/vibrant-edison-r9o798`)
```
pull claude/vibrant-edison-r9o798
npm run seed
npm run dev
```
1. Open http://localhost:5173 and log in as `buyer@demo.local` / `Password123`. You'll see the greeting and "Found on Unc 🎉".
2. In a second browser, log in as `vendor@demo.local` / `Password123` and make an offer with a price.
3. As the buyer, open the chat and try **Counter** or **Accept**.
4. **↗ Share** is at the top of every open request.

Notes:
- `npm run seed` resets the demo data and adds the demo story. It is optional: skip it to keep your own data.
- Link preview cards only work once the app is online with `APP_URL` set.
