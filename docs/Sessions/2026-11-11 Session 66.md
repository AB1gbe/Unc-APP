# 2026-11-11 Session 66: "pull main … yet it doesn't work"

## What was asked
The owner ran `git checkout main` and `pull main` (screenshot) and still didn't see the new look and photos.

## What we found
- `npm start` (used for the phone test, [[Step 53 - Test as an app on your phone for free]]) shows the **built** copy of the website in `client/dist/`. `pull` downloads the new code but didn't rebuild that copy, so the old look stayed ([[Mistakes and Fixes#M121]]).
- "Your branch is up to date with 'origin/main'" after `git checkout main` only compares with the last download; `pull main` is what fetches the new changes.

## What we did
- Root `package.json`: added `"prestart": "npm run build"`, so `npm start` always rebuilds the website first (a few seconds longer to start).
- Tested: `npm start` builds then serves (HTTP 200); `npm run e2e` → E2E OK.

## What the owner does (Windows cmd, in `C:\Users\a.baqer\Documents\Unc-APP`)
```
git checkout main
pull main
npm run build
npm start
```
(`npm run build` only this once; from the next pull on, `npm start` does it by itself.) Then press **Ctrl + F5** in the browser. For the demo photos in the sample requests: stop the server, delete `server\data`, run `npm run seed`, start again.
