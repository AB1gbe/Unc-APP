# 2026-10-25 Session 46: "Is it safe?" (winget's agreement question)

## What was asked
A screenshot of `winget install --id Cloudflare.cloudflared` asking "Do you agree to all the source agreements terms? [Y] Yes [N] No" about the `msstore` source. "Is it safe?"

## Answer
- Yes. It's Windows' own package installer (winget) asking once to accept the Microsoft Store's terms and to send the 2-letter country code (e.g. "BH") so the store can work. It doesn't install anything extra.
- Type `Y` and Enter. Or answer `N` and run `winget install --id Cloudflare.cloudflared --source winget`, which uses only the community source and doesn't ask.
- cloudflared itself is Cloudflare's official program.
