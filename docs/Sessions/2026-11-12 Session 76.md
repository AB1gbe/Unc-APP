# 2026-11-12 Session 76: A PDF of every tab and page

## What was asked
"Can you create a PDF of every tab and page in the app."

## What we did
1. Wrote `scripts/make-screens-pdf.mjs` ([[Step 67 - Screens PDF]]).
2. Fresh demo data (`npm run seed`), `npm start`, ran the script. Result: `docs/Design/Unc screens.pdf` with **39 screens on 80 pages** (12.8 MB). It has a cover, contents, and for each screen one computer page and one phone page:
   - Visitors (12): Home, Requests, a category, Shops, Categories, a request, a shop page, Sign up, Log in, Forgot password, Help, Terms
   - Buyer (16): Home, My requests, my request with offers, Post a request, Messages, a chat, Notifications, Account, Alerts, Saved, Orders, Wallet, Invite, Payment card, What people ask for, Help
   - Shop (4): Home, a buyer's request, Messages, Account with shop editor
   - Admin (1)
   - Arabic (6): Home, Requests, Shops, Categories, Chat, Account
3. The first run saved the file as `Unc%20screens.pdf` ([[Mistakes and Fixes#M134]]); fixed and renamed.
