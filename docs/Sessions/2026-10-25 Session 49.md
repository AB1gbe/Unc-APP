# 2026-10-25 Session 49: "listening" but the server stopped (port already in use)

## What was asked
A screenshot from the phone test: the folder was found (`C:\Users\a.baqer\Documents\Unc-APP`), `npm run build` and `npm run seed` worked, `npm start` printed "Unc API listening on http://localhost:4000", and then the prompt came straight back.

## What it was
- Port 4000 was still used by the earlier `npm run live` window, and the server's start-up code hid that error ([[Mistakes and Fixes#M103]]).
- The app folder on the owner's PC is `C:\Users\a.baqer\Documents\Unc-APP` (not in the home folder, as earlier notes assumed).

## What we did
1. Proved it in a small script: Express 5 passes `EADDRINUSE` to the `listen` callback.
2. Added `server/src/lib/listen.js` and used it in `server/src/index.js`: a clear message and exit code 1 when the port is taken.
3. Test `server/test/listen.test.js` (fails on the old code). `npm test`: 170 → **171**. Checked for real by running `npm start` twice.
4. Step 53 now says the window must stay busy, and what to do if the port is taken.
