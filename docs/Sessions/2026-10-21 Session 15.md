# 2026-10-21 Session 15: Push notifications to the phone for new offers

## What was asked
"Add push notifications to my phone for new offers."

## What we did
1. Chose **Web Push** (built into browsers; works with the installable website, free, no app store) → [[ADR-022 Push notifications]].
2. Server work:
   - installed `npm install web-push --workspace server` (0 vulnerabilities);
   - migration 10 `push_subscriptions`;
   - `lib/push.js`, `routes/push.js`;
   - a push after each new offer.
   - Wrote `server/test/push.test.js` (4 tests) with a fake push service. All tests pass: **97/97**.
3. Phone side:
   - service worker `client/public/sw.js`;
   - `client/src/push.js`;
   - the **Notifications on this phone** card on Account and on the 🔔 page;
   - logging out turns the device off.
4. Tried the real browser flow in headless Chromium:
   - the default mode blocks notifications ([[Mistakes and Fixes#M57]]);
   - the newer mode in a private profile refuses push ([[Mistakes and Fixes#M58]]);
   - in a normal profile, subscribing hung because the sandbox can't reach Google's push servers. That showed a stuck button and an English-only error, which we fixed ([[Mistakes and Fixes#M59]]).
5. Browser checks: `npm run e2e` (now also opens the card), `npm run e2e:ar` and `npm run e2e:devices` all OK.
6. Commit `0650185` pushed. Docs:
   - [[Push Notifications]], [[Step 22 - Push notifications]];
   - [[Environment Variables]] (`VAPID_*`);
   - [[API Reference]], [[Database Schema]], [[Folder Map]], [[Roadmap]].

Also logged a slip from session 13 that had been missed ([[Mistakes and Fixes#M56]]).

## Commands used (inside `Unc-APP`)
```
npm install web-push --workspace server
npm test
npm run build --workspace client
npm run seed
npm start
npm run e2e:devices
npm run e2e
npm run e2e:ar
npx web-push generate-vapid-keys
```
The `npm run seed` + `npm start` + `npm run e2e:devices` run used seeded data. `npm run e2e` and `npm run e2e:ar` ran against a fresh server. `npx web-push generate-vapid-keys` was run only to check that the command works.
