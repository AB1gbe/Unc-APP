# 2026-11-15 Session 100: Lighter sign-up vs scams

## What was asked
On point 2 of [[Honest Review 2026-11-15]] (lighter sign-up): "then scams would be easier".

## Answer (proposal, nothing built yet)
Scams mostly come from **posters** (fake flats with deposits, fake jobs with "visa fees", non-existent items), less from people replying (fake transfer screenshots, links; Unc already blocks links/numbers in chat and shows scam warnings). So keep the ID check **where money and trust are**, not for everyone. A **trust ladder**:

| Level | Needs | Can |
|---|---|---|
| Browse | nothing | look |
| Reply / chat | Bahrain phone number + SMS code (one account per number) | message about ads; shown as "Not ID-checked" |
| Post For sale / Wanted | phone + ID check | post; "ID-checked" badge |
| Housing, Jobs, businesses, big deals | ID check (+ CR) | everything |

Extra protection:
- new-account limits (a few chats a day, no links);
- sellers can allow only ID-checked people to contact them;
- the "Not ID-checked" label.

SMS costs money and needs a provider (Twilio or a Bahraini gateway); an email code can stand in until then.
