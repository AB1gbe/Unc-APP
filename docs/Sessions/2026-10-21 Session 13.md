# 2026-10-21 Session 13: Images, real profiles, a whole user experience, every device

## What was asked
1. "Add the ability to add images, create a user, make it look like a whole user experience, not just buying and selling fast and getting out."
2. (While working) "Make it optimized for the phones as well, for all devices."

## How we read it (the plan, built in this order, each step pushed separately)
1. A profile photo and a real profile.
2. The welcome step after sign-up.
3. A home page for members.
4. Images everywhere.
5. Saved requests (♡).
6. Notifications (🔔).

Phones and every screen size was added after step 2, when the owner asked for it.

Rules that stayed:
- Contact only through a request: profiles have no message button.
- KYC photos are never reused or shown.
- Chat photos are visible only to the two people in the conversation.
