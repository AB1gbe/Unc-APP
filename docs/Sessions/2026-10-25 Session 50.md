# 2026-10-25 Session 50: Port 4000 still in use during the phone test

## What was asked
A screenshot: `npm start` now shows the new message (from session 49) "Could not start Unc: Port 4000 is already in use…". So the fix reached the PC: the `npm run live` window is still running and pulled it by itself.

## Answer
- Easiest: run this test on another port, so nothing has to be found or stopped (two lines in cmd):
  ```
  set PORT=4001
  npm start
  ```
  Then `cloudflared tunnel --url http://localhost:4001`.
- Or find and stop what holds 4000: `netstat -ano | findstr :4000`, then `taskkill /PID <number> /F`.
- Step 53 now includes both.
