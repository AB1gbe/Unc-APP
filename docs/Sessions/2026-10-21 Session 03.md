# 2026-10-21 Session 03 — Testing email with a personal Gmail

## What was asked
After session 02 asked "which email provider?", the owner answered: *"my personal email just for testing"*.

## Decision
Use **Gmail SMTP with an App Password** for local testing. No domain or provider account needed. Not for production (≈500/day limit, sends as the personal address) — a provider with your own domain is still needed before launch ([[Email Sending#Set up real email — step by step]]). No new ADR: this is a configuration of [[ADR-011 Email delivery]], not a new design choice.

Security choice: the owner sets the App Password in their own `.env` on their own computer. It was **not** requested in chat and is never committed (`.env` is git-ignored).

## What we did
1. Added `npm run mail:test -- you@example.com` (`server/src/mail-test.js`): sends one email with the current settings and explains common failures, so the setup can be checked without clicking through the app.
2. Tested it three ways against a local SMTP server that requires a login: correct password → delivered; wrong password → `535` + "use an App Password" hint; wrong port → `ECONNREFUSED` + "check host/port, try 465" hint. Console mode prints the email.
3. `config.js`: for `smtp.gmail.com`, spaces are stripped from `SMTP_PASS` (Google shows App Passwords as `abcd efgh ijkl mnop`). Verified: `"abcd efgh ijkl mnop"` → `"abcdefghijklmnop"`.
4. Tests: 32/32 still pass.
5. Docs: Gmail walkthrough in [[Email Sending#Quick test with your personal Gmail (no domain needed)]], plus updates to [[Run the App Locally]], [[Environment Variables]], [[Folder Map]], [[Step 13 - Real email sending]].

## Options considered
| Option | Why / why not |
|---|---|
| **Gmail SMTP + App Password** ✅ | Uses the account the owner already has; 5 minutes |
| Resend free tier with its test sender | Can only send to the account's own address and needs an extra signup |
| Mailtrap / Ethereal (fake inboxes) | Emails never reach a real inbox — the owner wants to see them in their own email |
