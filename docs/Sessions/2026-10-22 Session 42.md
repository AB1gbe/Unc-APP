# 2026-10-22 Session 42: "I can't type anything" in the live window

## What was asked
A screenshot of the `npm run live` window (after pull request #14) with: "I can't type anything".

## What it was
- **Nothing is wrong.** That window is running the app (`api`, `web`) and the sync (`sync`). A running program owns its window, so typing does nothing there.
- The screenshot shows everything working:
  - the API restarted on port 4000;
  - the sync pulled the session 41 note;
  - then it pulled the merge of pull request #14. "0 changed files" is right: the merge changed nothing compared with what was already pulled.
- `../.env not found` is also fine: without a `.env` the app uses safe defaults (console email, showcase card payments).

## What to do
- To type commands, open a **second** Command Prompt, go to the `Unc-APP` folder, and type there. Leave the live window running.
- To stop the live window: click it and press **Ctrl + C**. If it asks "Terminate batch job (Y/N)?", type `Y` and press Enter.
