## A safety catch before coding
Deleting an account must not let a **banned** person delete and sign up again with the same ID. The identity check refuses an ID already in use, so wiping the ID record would have opened that door. Fix by design: banned members' ID fingerprints are kept in `banned_id_hashes` ([[ADR-043 Download and delete my data]]).
