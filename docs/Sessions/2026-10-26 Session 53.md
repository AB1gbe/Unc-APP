# 2026-10-26 Session 53: "Bad gateway 502" on the phone

## What was asked
Two screenshots (next morning): the phone shows Cloudflare's "Bad gateway, Error code 502, Host Error" for `glance-projection-making-referring.trycloudflare.com`, and the tunnel window repeats *"Unable to reach the origin service … dial tcp [::1]:4001: connectex: No connection could be made because the target machine actively refused it."*

## What it was
- The tunnel and Cloudflare work; nothing answers on the PC at port 4001 the way cloudflared asks: either the `npm start` window had stopped, or `localhost` became the IPv6 `[::1]` while the server only answers on IPv4 ([[Mistakes and Fixes#M104]]).

## What to do
1. Server window: `cd C:\Users\a.baqer\Documents\Unc-APP`, `set PORT=4001`, `npm start`, and it must stay busy.
2. Tunnel window: Ctrl + C, then `cloudflared tunnel --url http://127.0.0.1:4001`, and open the **new** address on the phone.
