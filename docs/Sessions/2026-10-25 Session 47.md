# 2026-10-25 Session 47: "Could not read package.json" when starting the phone test

## What was asked
A screenshot: `npm run seed` and `npm start` in `C:\Users\a.baqer` failing with `ENOENT … Could not read package.json`.

## What it was
- The commands ran in the home folder `C:\Users\a.baqer`, not in the app folder. That's the same thing as [[Mistakes and Fixes#M14]]. After reopening the Command Prompt (needed after installing cloudflared), it starts in the home folder again, so `cd Unc-APP` has to come first.
- Fix: `cd Unc-APP`, check the prompt shows `C:\Users\a.baqer\Unc-APP>`, then `npm run build`, `npm run seed`, `npm start`.
