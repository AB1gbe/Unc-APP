# 2026-10-21 Session 10 — One-word pull/push + Bahrain research

## What was asked
1. "Can you do a script where I type push or pull and it does that automatically, instead of me pasting it into cmd each time?"
2. "Is there anything similar to the app we are building here in Bahrain?"

## Part 1 — `pull` and `push`
- Built `scripts/git-helper.mjs`, `pull.cmd`, `push.cmd`, `.gitattributes` (keeps `.cmd` files with Windows line endings), npm scripts `pull`/`push`.
- Options considered: plain `.cmd` files with git commands (no safety checks, hard to read); a PowerShell script (blocked by default execution policy on many PCs); **a Node script + tiny `.cmd` launchers** ✅ (Node is already installed, same code works on Mac/Linux, room for safety checks).
- Tested in a stand-in setup (fake GitHub + "your PC" + "Claude" copies): 9 situations, all correct after fixing two bugs → [[Mistakes and Fixes#M38]], [[Mistakes and Fixes#M39]].
- How to use: [[Pull and Push]].

## Part 2 — Bahrain market research
- A research agent searched the web (≈46 searches) while the script was being built; the report is saved as [[Bahrain Market Research]], with every claim labelled verified/inferred/unconfirmed and sources listed.
- Headline: no direct equivalent found; pieces exist (Mourjan "ask-buy", OpenSooq "wanted to buy" ads, HomeX/Mismaar quotes, Garage Bahrain parts requests, Procural B2B); main indirect competitors dubizzle (ex-OLX) Bahrain and OpenSooq; scams are a documented problem; eKey for Business (via Beyon Connect) is the long-term identity route; CR status can be checked on Sijilat.
- Follow-ups added to [[Roadmap]] (Arabic/RTL, BHD, BenefitPay, eKey, CR check, sharing to WhatsApp).
